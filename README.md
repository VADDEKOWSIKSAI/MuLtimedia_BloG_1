# Travel & Multimedia Hub

A comprehensive web project featuring an interactive **Travel Destination Guide** and a dedicated **Multimedia Blog**.

## 🚀 Project Overview

This repository contains a collection of web pages designed to showcase iconic travel destinations and a curated selection of multimedia content, including music and movie trailers.

## 📂 Project Structure

- **[Travel Guide](./index.html)**: The main landing page featuring an interactive "Capture the Moment" gallery with draggable cards and detailed guides for:
  - Paris, France
  - Kyoto, Japan
  - New York City, USA
  - New Delhi, India
  - Sydney, Australia
- **[Multimedia Blog](./list/index.html)**: A dedicated space for media enthusiasts, sponsored by VKS™, featuring:
  - **Favorite All-Time Songs**: A collection of high-quality audio tracks.
  - **2026 Sankranthi Releases**: The latest movie trailers and posters from Tollywood.
- **Daily Exercises**: Folders `day4` through `day7` contain various HTML/CSS exercises and portfolio components.

## ✨ Features

- **Interactive UI**: Draggable and flippable cards for an engaging user experience.
- **Responsive Design**: Optimized for various screen sizes using modern CSS techniques.
- **Embedded Maps**: Real-time Google Maps integration for travel destinations.
- **Media Integration**: HTML5 `<audio>` and `<video>` tags for seamless playback.
- **Interactive Games**: A "Spell the City" mini-game integrated into the travel cards.

## 🛠️ Technologies Used

- **HTML5**: Semantic structure and multimedia elements.
- **CSS3**: Advanced layouts, animations, and grid systems.
- **JavaScript**: Interactive dragging logic and game mechanics.
